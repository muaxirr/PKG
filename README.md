# PKG (Лабораторные работы)

Репозиторий содержит лабораторные работы по дисциплине **«ПКГ»**. В каждой папке представлены отчёты, исходный код программ, а также готовые исполняемые файлы.

## 📁 Структура репозитория

Каждая лабораторная работа оформлена в отдельной директории и содержит:
* **Отчёт** в форматах `.pdf` и `.docx` с подробным описанием выполнения.
* **Исходный код** программы / приложения.
* **Исполняемые файлы (`.exe`)** для быстрого запуска и проверки.

## 🚀 Как запустить

Вы можете ознакомиться с теорией и результатами в папках с отчётами (`.pdf` / `.docx`) или запустить готовое приложение:

1. Перейдите в нужную папку лабораторной работы (например, `lab1`).
2. Найдите исполняемый файл с расширением `.exe` (если применимо) или откройте исходный код в соответствующей среде разработки.
3. Либо войти Релизы (Releases) там тоже есть файлы с расширением ` .exe`, можете скачать и войти.
