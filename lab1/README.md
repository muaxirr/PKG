# Лабораторная работа №1: Конвертер Цветовых Моделей

Дисциплина: **Программирование компьютерной графики**  
Тема: **Изучение и реализация алгоритмов конвертации цветовых моделей (RGB, CMYK, HSV, LAB, XYZ)**

Интерактивное приложение (Web + Desktop GUI) для исследования цветовых пространств, выполнения динамического пересчета координат цвета в режиме реального времени и контроля выхода за границы цветового охвата (*Out-of-Gamut*).

---

## 📌 Описание и возможности

- **Синхронный пересчет в реальном времени**: Изменение любого параметра в любой из моделей (RGB, CMYK, HSV, LAB) мгновенно обновляет все остальные координаты.
- **Тройная система ввода**:
  1. Системная графическая палитра (`<input type="color">`).
  2. Плавные слайдеры/ползунки (`<input type="range">`).
  3. Точные числовые поля ввода (`<input type="number">`).
- **Контроль цветового охвата (Out-of-Gamut Warning)**: Автоматическое определение и визуальное предупреждение пользователя при выходе цвета за пределы пространства sRGB (например, при некорректном или широком значении в LAB).
- **Десктопная и веб-версия**: Приложение может запускаться как в любом веб-браузере, так и в виде десктопного окна на базе `pywebview`.

## 📐 Математические алгоритмы конвертации

Приложение использует следующие цепочки преобразований:

1. **RGB ↔ CMYK**:
   $$\begin{aligned}
   K &= 1 - \max(R', G', B') \\
   C &= \frac{1 - R' - K}{1 - K}, \quad M = \frac{1 - G' - K}{1 - K}, \quad Y = \frac{1 - B' - K}{1 - K}
   \end{aligned}$$

2. **RGB ↔ HSV**:
   - $V = \max(R', G', B')$
   - $S = \frac{\Delta}{V}$, где $\Delta = \max - \min$
   - $H$ рассчитывается в зависимости от тонального сектора ($\Delta$).

3. **RGB ↔ CIE XYZ ↔ CIELAB**:
   - **sRGB Gamma Correction**:
     $$C_{\text{linear}} = \begin{cases} 
     \frac{C}{12.92}, & \text{если } C \le 0.04045 \\ 
     \left(\frac{C + 0.055}{1.055}\right)^{2.4}, & \text{если } C > 0.04045 
     \end{cases}$$
   - **Матричный переход в XYZ (D65)**.
   - **Нелинейное преобразование XYZ в CIELAB** с референсным белым $D65$ ($X_n=95.047, Y_n=100.000, Z_n=108.883$).

## 🚀 Запуск и сборка

### 1. Веб-версия
Просто откройте файл `index.html` в любом современном веб-браузере.

### 2. Десктопная версия (Python)
Установите зависимости и запустите `main.py`:

```bash
pip install pywebview
python main.py
```

### 3. Сборка исполняемого файла (.exe)
Для сборки приложения в отдельный исполняемый файл используется **PyInstaller**:

```bash
pip install pyinstaller
pyinstaller main.spec
```
Готовый исполняемый файл будет находиться в директории `dist/`.
