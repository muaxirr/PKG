# Лабораторная работа №5: Алгоритмы отсечения отрезков и многоугольников

Интерактивное графическое приложение, реализующее алгоритм отсечения отрезков Сазерленда-Коэна и алгоритм отсечения выпуклого многоугольника на языке Python (с использованием библиотеки Tkinter). Проект выполнен в рамках дисциплины «Программирование компьютерной графики» (ФПМИ БГУ, Группа 10А, Вариант №1).

---

## 🚀 Особенности реализации

* **Алгоритм Сазерленда-Коэна:** Реализовано битовое кодирование областей (9-зонирование плоскости) для быстрой классификации отрезков (тривиальное принятие/отклонение) и расчета точек пересечения с границами окна.
* **Вычислительная робастность ($\varepsilon = 10^{-7}$):** Во избежание типичных ошибок округления вещественных чисел (`float`) при работе с вертикальными/горизонтальными отрезками и прохождением через вершины внедрена система эпсилон-сравнений.
* **Интерактивный интерфейс:** Пользователь может зажать левую кнопку мыши внутри прямоугольного отсекающего окна и перемещать его по холсту в режиме реального времени с мгновенным пересчетом пересечений.

---

## 🛠 Стек технологий

* **Язык:** Python 3.x
* **Графика / UI:** Tkinter (стандартная библиотека GUI)
* **Парадигма:** Событийно-ориентированное программирование, математическое моделирование двумерной геометрии.

---

## 📦 Установка и запуск

1. Убедитесь, что у вас установлен **Python 3.x** (никаких сторонних зависимостей устанавливать не нужно, так как Tkinter входит в стандартную поставку Python).
2. Скачайте исходный файл приложения `main.py` в отдельную директорию.
3. Запустите скрипт из терминала или командной строки:

```bash
python main.py
```

---

## 🖱 Управление в приложении

* **Перемещение окна:** Зажмите левую кнопку мыши внутри голубого прямоугольника (отсекающего окна) и перетаскивайте его в нужную область экрана.
* **Отображение:** 
  * Серые линии — исходные отрезки до отсечения.
  * Ярко-зеленые линии — видимые фрагменты отрезков после отсечения.
  * Голубой прямоугольник — текущее отсекающее окно.
