# Лабораторная работа №3: Основы обработки цифровых изображений

Дисциплина: **Программирование компьютерной графики**  
Вариант: **№1** (*Построение и эквализация гистограммы изображения + Линейное контрастирование + Реализация поэлементных операций*)

Интерактивное настольное GUI-приложение для выполнения контрастирования, гистограммной обработки и поэлементных математических операций над растровыми изображениями.

---

## 📌 Описание и возможности

Приложение предоставляет удобный графический интерфейс для анализа и пространственной обработки изображений в реальном времени.

### Основные функции:
* **Линейное контрастирование**: Растяжение динамического диапазона яркости изображения до пределов $[0, 255]$.
* **Эквализация гистограммы**:
  * Полутоновые изображения (Grayscale).
  * Цветные изображения в пространстве **RGB** (поканальная эквализация).
  * Цветные изображения в пространстве **HSV** (эквализация только канала яркости $V$, что предотвращает цветовые искажения).
* **Сравнительный анализ гистограмм**: Построение сводного окна Matplotlib с исходным и обработанными изображениями, а также их канальными гистограммами (B, G, R).
* **Поэлементные (точечные) операции**:
  * **Сложение изображений** с альфа-смешиванием ($\alpha=0.5, \beta=0.5$).
  * **Вычитание изображений**.
  * **Инверсия** (Bitwise NOT).
  * **Логарифмическое преобразование** (усиление деталей в темных областях).
  * **Гамма-коррекция** с интерактивным регулятором ($\gamma \in [0.1, 5.0]$) через ускоренную таблицу пересчета (LUT).
* **Поддержка кириллицы в путях**: Чтение файлов через `np.fromfile` и `cv2.imdecode` исключает ошибки при наличии русских букв в пути к файлу.
* **Автоматическое выравнивание размеров**: Автоматический ресайзинг второго изображения под размеры первого при бинарных операциях (сложение/вычитание).

## 📐 Математические формулы и алгоритмы

### 1. Линейное контрастирование
Растягивает исходный диапазон яркостей $[a_{\text{min}}, b_{\text{max}}]$ до $[c, d] = [0, 255]$:

$$I_{\text{out}}(x, y) = \frac{I_{\text{in}}(x, y) - a_{\text{min}}}{b_{\text{max}} - a_{\text{min}}} \cdot (d - c) + c$$

### 2. Эквализация гистограммы
Нормированная функция пересчета на основе кумулятивной функции распределения (CDF):

$$h_{\text{eq}}(v) = \text{round}\left( \frac{\text{CDF}(v) - \text{CDF}_{\text{min}}}{N - \text{CDF}_{\text{min}}} \cdot 255 \right)$$

где $N$ — общее число пикселей изображения.

### 3. Гамма-коррекция (Power-Law)

$$I_{\text{out}} = 255 \cdot \left( \frac{I_{\text{in}}}{255} \right)^{\frac{1}{\gamma}}$$

При $\gamma > 1$ изображение становится светлее (проявляются детали в тенях), при $\gamma < 1$ — темнее.

### 4. Логарифмическое преобразование

$$I_{\text{out}} = c \cdot \ln(1 + I_{\text{in}})$$

### 5. Поэлементное сложение и вычитание

$$I_{\text{sum}} = \text{clip}(\alpha \cdot I_1 + \beta \cdot I_2 + \gamma)$$

$$I_{\text{sub}} = \text{clip}(I_1 - I_2)$$

## 🚀 Запуск и сборка

### 1. Установка зависимостей

```bash
pip install opencv-python numpy matplotlib pillow pyinstaller
```

### 2. Запуск приложения из исходного кода

```bash
python lab.py
```

### 3. Сборка исполняемого файла (.exe)

```bash
pyinstaller Lab3_ImageProcessing.spec
```

Готовый файл `Lab3_ImageProcessing.exe` будет помещен в директорию `dist/`.
