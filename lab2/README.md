# Лабораторная работа №2: Чтение и анализ информации из графических файлов

Дисциплина: **Программирование компьютерной графики**

Тема: **Автоматизированный парсинг метаданных растровых изображений (JPG, GIF, TIF, BMP, PNG, PCX)**

Настольное GUI-приложение для высокоскоростного сбора, парсинга и систематизации технических метаданных из графических файлов в выбранной директории. 

## 📌 Описание и возможности

* **Высокое быстродействие (Header Parsing)**: Извлечение системной информации происходит напрямую из заголовков файлов без декодирования пиксельного массива в оперативную память. Скорость обработки составляет до **1400 файлов/сек** (600 файлов объемом 2 ГБ обрабатываются за ~0.42 сек).
* **Широкая поддержка форматов**: Поддерживаются файлы `JPG`, `JPEG`, `GIF`, `TIF`, `TIFF`, `BMP`, `PNG`, `PCX`.
* **Извлечение ключевых параметров**:
  1. Имя файла и путь.
  2. Разрешение в пикселях (Ширина $\times$ Высота).
  3. Пространственное разрешение (DPI — Dots Per Inch).
  4. Глубина цвета и битовый режим (`1 bit`, `8 bit`, `24 bit True Color`, `32 bit RGBA/CMYK`).
  5. Алгоритмы и типы сжатия (`JPEG`, `Deflate`, `LZW`, `RLE`, `Uncompressed` и др.).
* **Расширенный анализ (Дополнительные метаданные)**:
  * **GIF**: Подсчет количества цветов в палитре и числа кадров анимации (`n_frames`).
  * **JPEG**: Детекция наличия таблиц/матриц квантования.
  * **TIFF**: Чтение специфических тегов сжатия (Group 4, LZW и др.).
* **Отказоустойчивость**: Безопасный перехват ошибок чтения битых или некорректных файлов с отображением сообщения об ошибке прямо в таблице.

## 📐 Алгоритмы извлечения данных

1. **Размер изображения**: 
   $$W \times H = \text{img.size}$$
2. **Пространственное разрешение**: 
   Извлекается из тегов `img.info['dpi']`. При отсутствии выводится статус `"Не задано"`.
3. **Глубина цвета**: 
   Определяется путем сопоставления внутреннего цветового режима `img.mode`:
   * `'1'` $\rightarrow$ 1 bit (Монохром)
   * `'L'` $\rightarrow$ 8 bit (Оттенки серого)
   * `'P'` $\rightarrow$ 8 bit (Палитра)
   * `'RGB'` $\rightarrow$ 24 bit (True Color)
   * `'RGBA'` $\rightarrow$ 32 bit (RGB + Альфа)
   * `'CMYK'` $\rightarrow$ 32 bit (Полноцветная печать)
4. **Теоретическая оценка производительности**:
   При обработке массива $N$ файлов вместо чтения всего физического объема данных $V_{\text{total}}$, программа считывает только заголовки $V_{\text{headers}} = N \cdot 4\text{ Кб}$.
   

   $$
   t_{\text{общая}} = t_{\text{I/O}} + t_{\text{parse}} \approx \frac{N \cdot 4\text{ Кб}}{S_{\text{SSD}}} + t_{\text{parse}}
   $$

## 🚀 Запуск и сборка

### 1. Установка зависимостей
```bash
pip install pillow pyinstaller
```

### 2. Запуск из исходного кода
```bash
python app.py
```

### 3. Сборка исполняемого файла (.exe)
```bash
pyinstaller app.spec
```
Готовый исполняемый файл будет помещен в папку `dist/`.
